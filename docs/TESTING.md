## 未使用真实账号验证的部分

- 手机号 + 密码登录：没有使用真实账号提交凭据，接口参数与错误处理按公开实现编写。
- 第三方 API 的扫码成功回调：Mock 仅返回 801，成功回调 803 的代码路径未触发。
- 游戏内悬浮 HUD：代码与注册通过，但自动化截图环境无法稳定注入键盘/鼠标，未截取世界内 HUD。
- 真实服务器联机：本模组为客户端模组，不影响联机；未做服务器兼容性测试。

这些路径均不影响已有的本地播放、搜索、歌单、二维码和第三方 API 功能。
